Local API

Everything this interface reads is served by the Flask app on this machine.

  • GET/api/persons/<id>One record with linked data
  • GET/api/search?q=Partial name search
  • GET/photo/<id>Cropped portrait
  • POST/api/recognizeDetect and match faces
